# 📦 Detecção de Objetos com YOLOv5
 
Este projeto tem como objetivo demonstrar o processo completo de **detecção de objetos utilizando o modelo YOLOv5**, desde a preparação dos dados até a análise de métricas de desempenho.
 
---
 
## 📘 Descrição
 
A detecção de objetos é uma das tarefas mais relevantes na área de Visão Computacional. Com o avanço de modelos como o YOLO (You Only Look Once), tornou-se possível identificar múltiplos objetos em imagens em tempo real com alta precisão.
 
Neste projeto, foi utilizada a arquitetura **YOLOv5**, desenvolvida pela Ultralytics, que oferece uma estrutura robusta e fácil de treinar com datasets personalizados.
 
---
 
## 🔍 O que você encontrará
 
- ✔️ Preparação dos dados para treinamento  

- ✔️ Montagem do ambiente no Google Colab  

- ✔️ Treinamento com 30 e 60 épocas  

- ✔️ Análise de perdas (losses) e métricas de desempenho  

- ✔️ Avaliação do modelo e considerações finais  
 
---
 
## 📊 Resultados
 
Os resultados obtidos mostram excelente desempenho nas métricas de **precisão**, **recall**, **mAP@0.5** e **mAP@0.5:0.95**, conforme detalhado no notebook, com gráficos e tabelas comparativas.
